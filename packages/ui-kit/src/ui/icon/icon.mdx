# Icon

Единая иконка из реестра дизайн-системы. Рисуется inline-`<svg>`, цвет наследует
через `currentColor`, размер — квадрат в пикселях. Реестр (`icon-paths`) —
**единственный источник иконок** в проекте: новые line/fill-иконки добавляются туда,
а не вставляются как разрозненные SVG по компонентам.

---

## Анатомия

- `name` — ключ из реестра; `size` — сторона квадрата; `title` — доступная подпись.
- Line- и fill-иконки различаются в реестре (обводка/заливка выбираются автоматически),
  каждая может нести свой `viewBox` (бренд-глифы вне сетки 24×24).

## Доступность

По умолчанию иконка декоративна и скрыта от скринридеров — так у соседнего текста не
задваивается озвучка. Если иконка **несёт смысл сама по себе**, задайте `title`
(тогда `role="img"` + доступное имя).

# Когда использовать

- иконка рядом с текстом (декоративная);
- самостоятельная значимая иконка (со `title`);
- иконка внутри `Button variant="icon"`.

# Когда **не** использовать

Не дублируйте подпись: если рядом уже есть текст, оставьте иконку декоративной.

```tsx
// ❌ Плохо — двойная озвучка
<span><Icon name="folder" title="Папка" /> Папка</span>

// ✅ Хорошо
<span><Icon name="folder" /> Папка</span>
```

Не хардкодьте `<svg>` в компонентах — добавляйте иконку в реестр.

## Токены

Цвет — любой `color` родителя через `currentColor` (обычно `--fg`, `--primary`,
`--color-danger`). Своих размерных токенов у иконки нет — размер задаётся пропом.

## Связанные компоненты

- [`Button`](?path=/docs/shared-primitives-button--docs) `variant="icon"` — кликабельная обёртка.
- [`Tag`](?path=/docs/shared-primitives-tag--docs) / [`Kbd`](?path=/docs/shared-primitives-kbd--docs) — иконка внутри метки/подсказки.

---

# Ответственность

Icon отвечает за отрисовку SVG из реестра, размер, наследование цвета и корректную
a11y-роль по наличию `title`. **Не отвечает** за клики и интерактив (оборачивайте в
`Button`), анимацию и прямое задание цвета (наследуется от родителя).
