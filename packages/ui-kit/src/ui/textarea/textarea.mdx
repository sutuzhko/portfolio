# Textarea

Многострочное поле ввода с подписью, подсказкой и состоянием ошибки. Разметку и
a11y даёт общий [`FieldFrame`](?path=/docs/shared-primitives-fieldframe--docs) —
поведение полностью совпадает с [`Input`](?path=/docs/shared-primitives-input--docs),
но для длинного текста.

---

## Анатомия

- Подпись `label[for]`, `<textarea rows>`, сообщение снизу.
- Ошибка приоритетнее подсказки; при ошибке — `aria-invalid` + `aria-describedby`.
- `forwardRef` (React Hook Form); пробрасывает нативные атрибуты (`rows`, `maxLength`…).

# Когда использовать

- длинный текст: био, описание проекта, статья;
- поле, где ожидаются переносы строк.

# Когда **не** использовать

Для однострочного значения — [`Input`](?path=/docs/shared-primitives-input--docs).

---

## Доступность

- `label[for]` + сообщение через `aria-describedby`; ошибка — `aria-invalid`.
- Поле изменяемо по высоте вручную (нативный resize) — клавиатурная доступность из коробки.

## Токены

Общие для полей: `--surface`/`--border`, `--ring` (фокус), `--color-danger` (ошибка),
`--radius-button` (см. `field/control.module.css`).

## Связанные компоненты

- [`FieldFrame`](?path=/docs/shared-primitives-fieldframe--docs) — обвязка поля.
- [`Input`](?path=/docs/shared-primitives-input--docs) — однострочный аналог.

---

# Ответственность

Textarea отвечает за связку подпись ↔ поле ↔ сообщение и a11y, проброс `ref`/нативных
атрибутов и визуальное состояние ошибки. **Не отвечает** за валидацию/текст ошибки
(снаружи), авто-рост высоты и Markdown-разметку содержимого.
