# PageIntro

Интро-абзац под заголовком экрана — короткое описание раздела на `Projects`,
`Experience`, `Contact`. Текст приходит с бэкенда (поля профиля `projectsIntro` /
`experienceIntro` / `contactIntro`), поэтому виджет сам решает, что показать по
значению пропа `intro`. Собран из UI Kit (`Text` + `Skeleton`) — своей вёрстки нет,
только раскладка и логика состояния.

---

## Анатомия

Три состояния по одному пропу `intro`:

- **строка** — рендерит абзац (`Text tone="muted"`);
- **`undefined`** — данные ещё грузятся → скелетон из двух строк высотой абзаца;
- **`null`** — интро для экрана нет → ничего не рендерит.

# Когда использовать

- одно-двухстрочное описание под заголовком раздела;
- любой экран, где вводный текст приходит с сервера и может грузиться.

# Когда **не** использовать

- для основного текста-био — это `About` (Markdown);
- для статичного текста интерфейса — обычный `Text` без логики состояний.

---

## Доступность

- На время загрузки контейнер помечается `aria-busy` + `aria-live="polite"`, поэтому
  появление текста корректно объявляется скринридеру (скелетон сам по себе нем).

## Токены

Высота строк скелетона — `--page-intro-line`, максимальная ширина/отступ — локальные
custom-property модуля; цвет текста — тон `muted` (`--fg-muted`).

## Связанные компоненты

- [`Text`](?path=/docs/shared-primitives-text--docs) / [`Skeleton`](?path=/docs/shared-primitives-skeleton--docs) — из них собран.
- [`Heading`](?path=/docs/shared-primitives-heading--docs) — заголовок раздела над интро.

---

# Ответственность

PageIntro отвечает за выбор «текст / скелетон / ничего» и за то, чтобы скелетон не
сдвигал вёрстку. **Не отвечает** за источник текста — его передаёт контейнер страницы
из профиля.
