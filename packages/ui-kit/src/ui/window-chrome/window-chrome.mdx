# WindowChrome

Низкоуровневый UI-компонент, отображающий элементы управления окном
в стиле macOS.

Компонент предназначен для использования внутри составных компонентов
(например, `Window`, `Modal`, `Dialog`, `Drawer`) и не содержит бизнес-логики.

---

## Особенности

- Доступен по умолчанию (ARIA).
- Поддерживает декоративный режим.
- Поддерживает любую комбинацию кнопок.
- Не управляет состоянием окна.
- Не знает о модальных окнах.

# Когда использовать

Используйте `WindowChrome`, если компоненту необходимо отображать элементы управления окном
в стиле macOS.

Например:

- окно приложения;
- модальное окно;
- панель;
- плавающее окно;
- окно редактора.

---

# Когда **не** использовать

Не используйте компонент как самостоятельное окно.

```tsx
// ❌ Плохо
<WindowChrome />
```

Компонент должен быть частью более крупной композиции.

```tsx
// ✅ Хорошо
<Window>
    <WindowChrome />
    <WindowContent />
</Window>
```

---

# Доступность

- Каждый «огонёк» — настоящий `<button>` с `aria-label` (`closeLabel`/`minimizeLabel`/`maximizeLabel`),
  поэтому доступен по `Tab` и срабатывает с клавиатуры.
- Цвет кнопок (красный/жёлтый/зелёный) — не единственный различитель: у каждой есть
  подпись и глиф при наведении.
- В декоративном режиме кнопок нет — и в дерево доступности ничего не попадает.

# Токены

Цвета «светофора» — фиксированные системные (`#ff5f57`/`#febc2e`/`#28c840`), глиф —
`--fg`; отступы/размеры кнопок — локальные значения хрома.

# Связанные компоненты

- [`Window`](?path=/docs/shared-components-window--docs) — `Card` + `WindowChrome`, готовое окно.
- [`Button`](?path=/docs/shared-primitives-button--docs) — для действий внутри окна, а не хрома.

---

# Ответственность

WindowChrome отвечает только за:

- отображение кнопок;
- aria-label;
- генерацию событий.

WindowChrome **не отвечает** за:

- открытие окна;
- закрытие окна;
- минимизацию приложения;
- изменение размеров окна;
- состояние модального окна.
