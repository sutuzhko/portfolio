# Kbd

Клавиша на клавиатуре — для подсказок горячих клавиш (`⌘+K`, `Enter`, `Esc`).
Рендерит семантический `<kbd>` с «клавишным» видом.

---

## Анатомия

- Корень — `<kbd>` с моноширинным шрифтом.
- Одна клавиша = один `Kbd`. Сочетание/последовательность — несколько `Kbd` подряд
  (с разделителем между ними при необходимости).

# Когда использовать

- подсказка горячей клавиши рядом с действием;
- строка помощи в консоли (`⌘+K`);
- легенда клавиатурной навигации.

# Когда **не** использовать

Не используйте `Kbd` для обычного инлайн-кода — для него `Text family="mono"` или `<code>`.

```tsx
// ❌ Плохо
<Kbd>npm install</Kbd>

// ✅ Хорошо
<Text as="span" family="mono">npm install</Text>
```

---

## Доступность

- Семантический `<kbd>` сообщает вспомогательным технологиям, что это ввод с клавиатуры.
- `Kbd` — только визуальная подсказка: он не перехватывает нажатия. Реальный хоткей
  вешается на документ/поле (см. `shared/lib/keyboard`).

## Токены

`--raised`/`--border` (фон и рамка «клавиши»), `--fg-muted`, `--radius-button`, `--font-mono`.

## Связанные компоненты

- [`Text`](?path=/docs/shared-primitives-text--docs) `family="mono"` — для инлайн-кода.
- Хелпер `shared/lib/consoleShortcut()` возвращает `⌘K`/`Ctrl+K` под платформу — его
  результат и кладут в `Kbd`.

---

# Ответственность

Kbd отвечает за семантику `<kbd>` и «клавишный» вид символа. **Не отвечает** за
обработку нажатий (это не поле ввода) и за локализацию (символы клавиш универсальны).
