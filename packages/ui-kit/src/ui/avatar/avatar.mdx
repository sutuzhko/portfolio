# Avatar

Аватар: фото или инициалы на цветном фоне. Размер квадрата и доступная подпись
выводятся из `name`.

---

## Анатомия

- Есть `src` → фото (`<img alt={name}>`). Нет → инициалы (`role="img"`, `aria-label={name}`).
- `color` задаёт сплошной фон (контрибьюторы); без него — зелёный градиент.
- Размер шрифта инициалов масштабируется от `size`.

# Когда использовать

- аватар пользователя/автора;
- метки контрибьюторов проекта;
- заглушка вместо отсутствующего фото.

# Когда **не** использовать

Не используйте `Avatar` как декоративную картинку — он всегда несёт доступную
подпись именем. Для декоративных изображений берите `<img aria-hidden>`.

---

## Доступность

- Инициалы: `role="img"` + `aria-label={name}` — скринридер читает имя, а не буквы.
- Фото: `alt={name}` — та же подпись.
- Цвет фона контрибьютора не должен быть единственным различителем — рядом всегда
  есть имя/подсказка.

## Токены

Градиент инициалов — `--primary` → `--color-primary-bright`, текст — `--fg`,
скругление — `--radius-pill` (круг). Цвет контрибьютора приходит пропом (данные).

## Связанные компоненты

- [`Skeleton`](?path=/docs/shared-primitives-skeleton--docs) — заглушка на время загрузки фото.
- [`Icon`](?path=/docs/shared-primitives-icon--docs) — не путать: Icon декоративен, Avatar именован.

---

# Ответственность

Avatar отвечает за выбор режима (фото/инициалы), генерацию инициалов и подписи из
`name`, размер и фон. **Не отвечает** за загрузку и ретрай изображения, скелетон
загрузки (его рисует контейнер данных) и локализацию имени.
