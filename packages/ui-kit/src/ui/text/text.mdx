# Text

Универсальный примитив текста. Отделяет **визуальный размер и тон** от
**семантического тега**: любой размер шкалы доступен на любом строчном или блочном
элементе. Весь текст интерфейса, кроме заголовков (для них — `Heading`), проходит
через `Text`, чтобы шкала, цвета и начертания не разъезжались по проекту.

---

## Анатомия

- Тег выбирается через `as` (`p` по умолчанию; `span`, `label`, `strong`, `em`, `small`, `div`).
- Визуал независим от тега: `size` (шкала), `tone` (смысл), `weight`, `family` (sans/mono).
- `truncate` — обрезка одной строкой с многоточием.

# Когда использовать

- абзацы и подписи;
- вторичный/третичный текст (`muted`, `dim`);
- моноширинные подписи и технические метки;
- инлайн-акценты внутри абзаца.

# Когда **не** использовать

Для заголовков — `Heading` (он держит порядок уровней страницы). Цвет не задавайте
инлайн-стилем — выбирайте `tone`.

```tsx
// ❌ Плохо — заголовок сделан «крупным текстом»
<Text size="body" weight="bold">Проекты</Text>

// ✅ Хорошо
<Heading level="h2">Проекты</Heading>
```

---

## Доступность

- `as` выбирает верный семантический тег: `label` для подписи поля, `strong`/`em` для
  смыслового акцента (а не только визуального).
- Смысловые тона (`danger`, `primary`) не должны быть **единственным** носителем смысла —
  дублируйте текстом/иконкой (цвет не воспринимают дальтоники).

## Токены

Размеры — `--font-size-*` (шкала), цвета — `--fg` / `--fg-muted` / `--fg-dim` / `--primary` /
`--color-danger`, семейства — `--font-sans` / `--font-mono`.

## Связанные компоненты

- [`Heading`](?path=/docs/shared-primitives-heading--docs) — для заголовков.
- [`Kbd`](?path=/docs/shared-primitives-kbd--docs) — для клавиш вместо `mono`-текста.

---

# Ответственность

Text отвечает за применение размера/тона/начертания из токенов, выбор семантического
тега и одностроковую обрезку. **Не отвечает** за иерархию заголовков (`Heading`),
локализацию содержимого и типографику пунктуации.
