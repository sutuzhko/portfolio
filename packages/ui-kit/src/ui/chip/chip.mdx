# Chip

Переключаемый чип-фильтр (технология, контрибьютор). Это кнопка-тоггл с
семантикой `aria-pressed` — состояние выбора доступно скринридеру. Для
**неизменяемой** метки используйте [`Tag`](?path=/docs/shared-primitives-tag--docs).

---

## Анатомия

- Корень — `<button type="button" aria-pressed>`.
- Управляется снаружи: `selected` (визуал + `aria-pressed`) и `onClick` (запрос на
  переключение). Своего состояния чип не хранит — это делает потребитель.

# Когда использовать

- фильтр с состоянием вкл/выкл;
- множественный выбор технологий/контрибьюторов;
- быстрый переключатель в панели фильтров.

# Когда **не** использовать

- для неизменяемой метки — `Tag`;
- для взаимоисключающего «один из нескольких» — `Segmented`.

```tsx
// ❌ Плохо — одиночный выбор набором чипов
// ✅ Хорошо — Segmented для «один из»
<Segmented options={sortOptions} value={sort} onChange={setSort} />
```

---

## Доступность

- Роль `button` + `aria-pressed` — скринридер сообщает состояние «нажат/не нажат».
- Полноценный фокус и клавиатура (`Enter`/`Пробел`) из коробки — потому это `<button>`,
  а не `div`.
- `disabled` убирает чип из tab-порядка.

## Токены

`--primary` (заливка выбранного), `--raised`/`--border` (невыбранный), `--fg`/`--fg-muted`,
`--radius-button`, `--ring` (кольцо фокуса), `--font-mono`.

## Связанные компоненты

- [`Tag`](?path=/docs/shared-primitives-tag--docs) — неинтерактивный аналог.
- [`Segmented`](?path=/docs/shared-components-segmented--docs) — взаимоисключающий выбор.

---

# Ответственность

Chip отвечает за семантику тоггла (`aria-pressed`) и визуал выбранного состояния.
**Не отвечает** за хранение состояния выбора (снаружи), логику фильтрации данных и
локализацию подписи.
