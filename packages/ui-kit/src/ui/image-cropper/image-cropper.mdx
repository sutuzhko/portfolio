# Shared / components / ImageCropper

Кадрирование **квадратной** области изображения перетаскиванием и масштабом.
Картинка всегда покрывает вьюпорт (без зазоров), круглая маска показывает, как
результат будет выглядеть скруглённым аватаром, сетка «правило третей» помогает
кадрировать.

Компонент отдаёт наружу `CropRect { x, y, size }` — квадрат в пикселях исходного
изображения (для серверного `cropX/Y/Width/Height`). Вычисления вынесены в чистый
`crop-math` и покрыты юнит-тестами.

## Возможности

- Перетаскивание (pointer events + `touch-action: none` для тача).
- Масштаб ползунком и кнопками − / +.
- `onChange` вызывается при загрузке, зуме и сдвиге — родитель хранит последний кадр.

## Доступность

- Ползунок и кнопки масштаба имеют `aria-label`.
- Картинка декоративна (`alt=""`); перетаскивание не выделяет и не тянет изображение.

## Пример использования
