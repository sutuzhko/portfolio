# Toggle

Тумблер-переключатель с семантикой `switch` (`role="switch"` + `aria-checked`).
Меняет состояние **мгновенно** — без кнопки «Сохранить».

---

## Анатомия

- Корень — `<button role="switch" aria-checked>` с ползунком-`thumb` (декоративным).
- Управляется снаружи: `checked` + `onCheckedChange(next)`.
- `compact` — уменьшенный размер для флагов в формах.

# Когда использовать

- мгновенное вкл/выкл (тема, видимость проекта, флаг настройки);
- бинарное состояние, применяемое сразу.

# Когда **не** использовать

- выбор одного из нескольких — [`Segmented`](?path=/docs/shared-components-segmented--docs);
- отложенное согласие с сабмитом формы — нативный чекбокс уместнее по семантике.

```tsx
// ❌ Плохо — «switch» там, где нужен выбор из вариантов
<Toggle checked={theme === 'dark'} onCheckedChange={...} />

// ✅ Хорошо
<Segmented options={themeOptions} value={theme} onChange={setTheme} />
```

---

## Доступность

- `role="switch"` + `aria-checked` — озвучивается как «вкл/выкл».
- **Требует доступного имени**: `aria-label` или связанный `<label>`.
- Полноценная клавиатура (`Пробел`/`Enter`) и фокус, потому что это `<button>`.

## Токены

`--primary` (включённый трек), `--raised`/`--border` (выключенный), `--radius-stadium`
(трек), `--ring` (фокус); размер ползунка — локальные переменные модуля.

## Связанные компоненты

- [`Segmented`](?path=/docs/shared-components-segmented--docs) — выбор из нескольких.
- [`Chip`](?path=/docs/shared-primitives-chip--docs) — множественный выбор-тоггл.

---

# Ответственность

Toggle отвечает за семантику `switch`/`aria-checked` и вызов `onCheckedChange` со
следующим значением. **Не отвечает** за хранение состояния (снаружи), подпись рядом
(даёт потребитель) и сохранение на сервер.
