# Shared / components / Modal

Модальное окно поверх страницы: затемнённый фон, центрированная панель, слоты
заголовка/подзаголовка/тела/футера. Управляется извне пропом `open`.

- Закрытие по **Escape**, клику по фону и крестику.
- Блокирует скролл фона, портируется в `body` (не зависит от контекста верстки).
- Фон — `<button>` (a11y: не вешаем onClick на неинтерактивный `div`); панель —
  `role="dialog" aria-modal aria-labelledby`.

## Когда использовать

- Подтверждения, короткие формы, кадрирование изображения — то, что требует фокуса
  и перекрывает страницу.
- **Не** для тостов (см. `features/toaster`) и выпадающих меню (см. `Menu`).
