# Input

Текстовое поле ввода с подписью, подсказкой и состоянием ошибки. Разметку и a11y
поля даёт общий [`FieldFrame`](?path=/docs/shared-primitives-fieldframe--docs).

---

## Анатомия

- Подпись `label[for]` (id генерируется через `useId`), сам `<input>`, сообщение снизу.
- Ошибка приоритетнее подсказки; при ошибке — `aria-invalid` + `aria-describedby`.
- `forwardRef` — работает с React Hook Form; нативные атрибуты `<input>` пробрасываются.

# Когда использовать

- любое однострочное поле формы (логин, поиск, ссылка);
- поле под управлением React Hook Form + Zod.

# Когда **не** использовать

- многострочный ввод — [`Textarea`](?path=/docs/shared-primitives-textarea--docs);
- выбор из фиксированного списка — [`Select`](?path=/docs/shared-primitives-select--docs).

---

## Доступность

- `label[for]` связывает подпись с полем; без видимой подписи обязателен `aria-label`.
- Ошибка: `aria-invalid="true"` + `aria-describedby` на сообщение — скринридер читает
  причину невалидности.
- Красная рамка ошибки дублируется текстом (цвет не единственный сигнал).

## Токены

Общие для полей: `--surface`/`--border` (рамка), `--ring` (фокус), `--color-danger`
(ошибка), радиус `--radius-button` (см. `field/control.module.css`).

## Связанные компоненты

- [`FieldFrame`](?path=/docs/shared-primitives-fieldframe--docs) — обвязка (label/сообщение).
- [`Textarea`](?path=/docs/shared-primitives-textarea--docs) / [`Select`](?path=/docs/shared-primitives-select--docs) — родственные поля.

---

# Ответственность

Input отвечает за связку подпись ↔ поле ↔ сообщение и их a11y, проброс `ref`/нативных
атрибутов и визуальное состояние ошибки. **Не отвечает** за валидацию (Zod/RHF снаружи),
текст ошибки/локализацию и маски ввода.
