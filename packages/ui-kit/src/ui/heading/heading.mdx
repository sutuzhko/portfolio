# Heading

Заголовок дизайн-системы. Ключевая идея — **визуальный размер (`level`) отделён от
семантического тега (`as`)**. Так на странице сохраняется корректный порядок
заголовков (`h1 → h2 → h3`) независимо от того, насколько крупно они выглядят.

---

## Анатомия

- `level` — визуальный размер по шкале (`display`, `h1`, `h2`, `h3`).
- `as` — семантический тег (`h1`–`h6`); по умолчанию выводится из `level`.
- `tone` — смысловой цвет.

## Размер отдельно от семантики

Крупный герой-заголовок в середине страницы не должен быть вторым `h1`. Оставляем
визуальный `display`, но понижаем тег до `h2` — `play` проверяет уровень в DOM.

# Когда использовать

- заголовки страниц и разделов;
- герой-заголовок (`display`);
- подзаголовки карточек и панелей (`h3`).

# Когда **не** использовать

Для обычного текста, подписей и меток — `Text`.

```tsx
// ❌ Плохо — абзац оформлен заголовком
<Heading level="h3">Короткое описание проекта…</Heading>

// ✅ Хорошо
<Text tone="muted">Короткое описание проекта…</Text>
```

---

## Доступность

- Порядок заголовков (`h1 → h2 → h3`, без пропусков) — часть навигации для скринридеров.
  `as` позволяет держать порядок, не жертвуя размером.
- На странице ровно один `h1`. Крупные акценты ниже по документу — `level="display"`
  с понижением `as`.

## Токены

Размеры — `--font-size-*` (шкала), цвета — `--fg` / `--fg-muted` / `--primary`,
семейство — `--font-sans`.

## Связанные компоненты

- [`Text`](?path=/docs/shared-primitives-text--docs) — весь остальной текст.
- [`SectionLabel`](?path=/docs/shared-primitives-sectionlabel--docs) — моно-метка раздела над заголовком.

---

# Ответственность

Heading отвечает за визуальный размер из шкалы, выбор семантического тега и тон.
**Не отвечает** за порядок заголовков (его обеспечивает автор экрана через `as`),
отступы вокруг заголовка (раскладка) и локализацию текста.
