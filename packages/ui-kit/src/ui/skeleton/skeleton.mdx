# Skeleton

Базовый плейсхолдер загрузки. По конвенции проекта **любые данные с бэкенда рисуют
скелетон, пока грузятся** — без «Loading…», прыжков раскладки и пустот, в каждом
месте, где эти данные появятся.

---

## Анатомия

- Корень — декоративный `<span aria-hidden>` с бегущим бликом (shimmer).
- Размер и радиус — произвольные CSS-значения, чтобы точно повторять форму контента.

# Когда использовать

- ожидание данных с бэкенда (в каждом месте, где они появятся);
- первичная загрузка списка/карточки/страницы.

# Когда **не** использовать

- для мгновенных клиентских состояний без запроса;
- вместо сообщения об ошибке — у ошибки своё состояние ([`ErrorState`](?path=/docs/shared-primitives-errorstate--docs)).

---

## Доступность

- Скелетон декоративен (`aria-hidden`) — скринридеры его не читают.
- **Статус загрузки объявляет контейнер данных** через `aria-busy`/`aria-live`, а не
  сам скелетон.
- Shimmer гасится при `prefers-reduced-motion: reduce` — плейсхолдер остаётся, движение уходит.

## Токены

`--color-raised` (подложка), `--radius-sm` (радиус по умолчанию). Форму задаёт
потребитель, повторяя размеры контента.

## Связанные компоненты

- [`Avatar`](?path=/docs/shared-primitives-avatar--docs) / [`Card`](?path=/docs/shared-primitives-card--docs) — контент, который скелетон заменяет на время загрузки.

---

# Ответственность

Skeleton отвечает за визуальный плейсхолдер нужной формы и сокрытие от скринридеров.
**Не отвечает** за объявление статуса загрузки (это контейнер) и логику запроса/ретрая.
