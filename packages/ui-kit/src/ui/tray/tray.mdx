# Tray

Общий «трей» свёрнутых окон внизу справа экрана. `TrayPortal` порталит свою пилюлю
в единственный на страницу контейнер, поэтому окна из разных источников — консоль
и раннер — складываются в один аккуратный стек, а не перекрывают друг друга.

Корень трея создаётся лениво и переиспользуется (по data-атрибуту), так что каждый
новый `TrayPortal` кладёт содержимое в тот же контейнер. Сам контейнер прозрачен
для кликов (`pointer-events: none`) — активны только пилюли внутри, поэтому пустой
трей не перехватывает события страницы.

---

## Стек пилюль

Две пилюли из независимых виджетов, порталенные в один трей.

## Когда использовать

- Свёрнутое окно-оверлей, к которому нужен быстрый возврат (консоль, раннер игры).

## Когда НЕ использовать

- Тосты — у них свой стек и слой (`--z-toast` выше трея).
- Обычные поповеры/дропдауны — им портал в трей не нужен.

## Связанные компоненты

- [`DockPill`](?path=/docs/shared-components-dockpill--docs) — пилюля, живущая в трее.
