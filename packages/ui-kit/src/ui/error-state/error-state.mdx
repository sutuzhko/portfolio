# ErrorState

Единое состояние ошибки загрузки в стиле терминала: карточка с красной меткой
`// error`, сообщением и моно-кнопкой повтора. Используется на всех экранах,
привязанных к API (Projects, Project, Experience, Contact, Home), чтобы ошибки
выглядели одинаково и в стиле сайта.

---

## Анатомия

- Корень — `<div role="alert">`: ошибка объявляется вспомогательным технологиям сразу.
- Метка `// error`, локализованное сообщение (`message`) и кнопка повтора.
- Кнопка показывается **только** вместе с `onRetry`.

# Когда использовать

- ошибка загрузки данных секции/страницы с возможностью повтора;
- недоступность внешнего сервиса (например, статистики).

# Когда **не** использовать

- для загрузки — это [`Skeleton`](?path=/docs/shared-primitives-skeleton--docs);
- для пустого результата без ошибки — своё «пусто»-состояние экрана;
- для сиюминутных уведомлений — это `Toast`.

---

## Доступность

- `role="alert"` — сообщение зачитывается сразу, без ожидания фокуса.
- Повтор — настоящий `<button>` с фокусом и клавиатурой (`Enter`/`Пробел`).
- Красная метка не единственный носитель смысла: рядом всегда есть текст ошибки.

## Токены

`--surface`/`--border` (карточка), `--color-danger` (метка), `--font-mono`,
`--radius-card`.

## Связанные компоненты

- [`Skeleton`](?path=/docs/shared-primitives-skeleton--docs) — состояние загрузки (до ошибки).
- [`Button`](?path=/docs/shared-primitives-button--docs) — как оформлена кнопка повтора (вариант mono).

---

# Ответственность

ErrorState отображает факт ошибки и даёт действие «повторить». **Не отвечает** за сам
запрос и его состояние — это делает контейнер страницы.
