# DockPill

Свёрнутое окно в «трее» — компактная пилюля со «светофором» и моно-подписью.
Из неё собран трей консоли и раннера: жёлтый свет и клик по подписи разворачивают
окно обратно, зелёный — сразу на всю ширину, красный — закрывают.

Компонент **презентационный** и переиспользуемый: он ничего не знает о конкретном
окне, только показывает подпись и пробрасывает три действия. Позиционирование и
стыковку нескольких пилюль обеспечивает [`Tray`](?path=/docs/shared-components-tray--docs).

## Доступность

- «Светофор» — три кнопки с `aria-label` (передаются пропами `closeLabel` /
  `restoreLabel` / `maximizeLabel`), доступны с клавиатуры.
- Подпись — тоже кнопка: разворачивает окно кликом или Enter.

## Связанные компоненты

- [`Tray`](?path=/docs/shared-components-tray--docs) — контейнер, стыкующий пилюли.
- [`WindowChrome`](?path=/docs/shared-components-window--docs) — «светофор» окна.
