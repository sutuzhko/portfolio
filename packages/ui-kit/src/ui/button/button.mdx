# Button

Базовая кнопка дизайн-системы: один семантический `<button>` с CVA-вариантами под
роли действий редизайна. Кнопка запускает **действие** (сабмит, открытие оверлея,
команда) — для перехода по URL используйте ссылку (см. [«Когда не использовать»](#когда-не-использовать)).

---

## Анатомия

- Корень — нативный `<button>`; все атрибуты (`onClick`, `type`, `aria-*`, `name`…)
  пробрасываются прозрачно.
- `variant` задаёт визуальную роль, `size` — плотность, `fullWidth` — растяжение.
- Контент — произвольные `children`: текст, `текст + <Icon>` или одна иконка
  (для `variant="icon"`).

## Когда использовать

- запуск действия: сабмит формы, открытие модалки/консоли, выполнение команды;
- **один `primary` на секцию** — он ведёт к главной цели.

## Когда **не** использовать

Для навигации по URL используйте ссылку (`<a>` / `<Link>`), стилизованную под
кнопку, а не `Button` с ручным `onClick` + программной навигацией — так
сохраняются семантика, средний клик/«открыть в новой вкладке» и доступность.

```tsx
// ❌ Плохо
<Button onClick={() => navigate('/projects')}>Проекты</Button>

// ✅ Хорошо
<Link to="/projects" className={buttonLikeClass}>Проекты</Link>
```

Для `variant="icon"` **всегда** задавайте `aria-label` — иначе у кнопки нет
доступного имени.

```tsx
// ❌ Плохо — скринридер озвучит «кнопка», и всё
<Button variant="icon"><Icon name="moon" /></Button>

// ✅ Хорошо
<Button variant="icon" aria-label="Сменить тему"><Icon name="moon" /></Button>
```

## Доступность

- Семантический `<button>` — фокусируется с клавиатуры, срабатывает по `Enter`/`Пробел`.
- Видимое кольцо фокуса (токен `--ring`) не убирается.
- `disabled` убирает кнопку из tab-порядка и глушит клик.
- Иконочный вариант требует `aria-label`; при `disabled` контекст объясняет причину
  недоступности рядом (это ответственность экрана, не кнопки).

## Токены

`--primary` / `--fg` / `--border` / `--raised` (фон и рамка вариантов),
`--radius-button` (скругление), `--ring` (кольцо фокуса), `--font-mono` (вариант `mono`).
Значения не хардкодятся — только переменные.

## Связанные компоненты

- [`Icon`](?path=/docs/shared-primitives-icon--docs) — контент icon-варианта и иконки в подписи.
- [`Kbd`](?path=/docs/shared-primitives-kbd--docs) — ярлык внутри mono-кнопки.
- `Toggle` / `Segmented` — для переключений, а не действий.

---

# Ответственность

Button отвечает за:

- визуальный вариант, размер, растяжение;
- проксирование нативных атрибутов и событий;
- безопасный `type="button"` по умолчанию.

Button **не отвечает** за:

- навигацию (это ссылки);
- состояние загрузки и спиннер (задаёт потребитель);
- локализацию подписи (приходит через `children`).
