# SectionLabel

Моноширинная зелёная метка секции в духе комментария кода — `// стек`,
`// активность`, `// избранные проекты`. Единый визуальный якорь для секций
публичных экранов: стиль и вертикальный отступ заголовков не расходятся от секции
к секции. Префикс `//` — часть контента (приходит из i18n); компонент отвечает
только за оформление.

---

## Анатомия

- По умолчанию `<h2>` — метка озаглавливает секцию.
- `as` меняет тег (`h3` для вложенной секции; `div`/`span`/`p` — когда заголовок в
  разметке уже есть).
- Отступы — локальные переменные `--section-label-gap-top/bottom` (переопределяемы).

# Когда использовать

- заголовок секции публичного экрана (`// обо мне`, `// стек`);
- любой раздел, которому нужен единый «кодовый» акцент.

# Когда **не** использовать

- как основной заголовок страницы — для крупной типографики есть
  [`Heading`](?path=/docs/shared-primitives-heading--docs);
- для обычного текста/подписей — это [`Text`](?path=/docs/shared-primitives-text--docs).

---

## Доступность

- `<h2>` по умолчанию встраивает метку в порядок заголовков — важно для навигации
  скринридеров по разделам.
- Если рядом уже есть заголовок нужного уровня, понизьте тег через `as="span"`, чтобы
  не плодить лишние заголовки.

## Токены

Цвет — `--primary`, шрифт — `--font-mono`, отступы — `--section-label-gap-top/bottom`.

## Связанные компоненты

- [`Heading`](?path=/docs/shared-primitives-heading--docs) — крупный заголовок под меткой.
- [`Text`](?path=/docs/shared-primitives-text--docs) — обычный текст секции.

---

# Ответственность

SectionLabel отвечает за единый стиль/отступ метки секции и корректную семантику
заголовка. **Не отвечает** за сам текст и префикс `//` (это i18n) и за раскладку
секции с действиями рядом.
