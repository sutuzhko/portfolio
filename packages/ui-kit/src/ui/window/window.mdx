# Window

Составное «терминальное окно» редизайна: поверхность `Card` со светофором
`WindowChrome` в шапке, подписью и слотом для инструментов.

Это **обособленная сущность UI Kit**, а не примитив. Экраны редизайна
собираются из готовых окон, а не из карточки и светофора по отдельности —
поэтому окно живёт и документируется в Storybook наравне с атомами.

---

## Из чего собрано

- `Card` (`padding="none"`) — поверхность, рамка, скругление;
- `WindowChrome` — светофор с проксированием обработчиков;
- шапка: подпись (`title`) + слот `toolbar`;
- тело: `children` (с отступами или `flush`).

## Варианты использования

### Декоративное окно

# Когда использовать

- окно приложения / секция-«терминал» на публичных экранах;
- модальное окно и диалог подтверждения;
- панель кабинета с вкладками в шапке.

# Когда **не** использовать

Не используйте `Window` как чистый контейнер без оконной семантики — для этого
есть `Card`.

```tsx
// ❌ Плохо — окно ради рамки
<Window title="">{content}</Window>

// ✅ Хорошо
<Card>{content}</Card>
```

---

# Доступность

- Кнопки светофора приходят из `WindowChrome` — настоящие `<button>` с `aria-label`
  (`closeLabel`/`minimizeLabel`/`maximizeLabel`), доступные с клавиатуры.
- Само окно **не** реализует фокус-трап и модальную семантику (`role="dialog"`,
  `aria-modal`) — это добавляет слой-владелец, когда `Window` играет роль модалки.
- Слот `toolbar` наследует доступность вложенных компонентов (например, `Tabs`).

# Токены

Наследует токены [`Card`](?path=/docs/shared-primitives-card--docs) (`--surface`/`--border`/`--radius-card`)
и [`WindowChrome`](?path=/docs/shared-primitives-windowchrome--docs); подпись шапки — `--font-mono`, `--fg-muted`.

# Связанные компоненты

- [`Card`](?path=/docs/shared-primitives-card--docs) + [`WindowChrome`](?path=/docs/shared-primitives-windowchrome--docs) — из чего собрано.
- [`Tabs`](?path=/docs/shared-components-tabs--docs) — типовое наполнение слота `toolbar`.

---

# Ответственность

Window отвечает за:

- сборку шапки (светофор + подпись + тулбар) и тела;
- проксирование обработчиков в `WindowChrome`;
- отступы тела (`flush`).

Window **не отвечает** за:

- состояние открытия/закрытия и фокус-трап модалки (слой выше);
- перетаскивание и изменение размера;
- локализацию подписей и меток.
