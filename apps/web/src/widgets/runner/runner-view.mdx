# Runner

Оверлей-раннер, который **запускает реальные проекты пользователя** прямо на сайте:
проект встраивается через `<iframe>` в оконный «хром» со светофором (свернуть в
трей, развернуть на всю ширину, закрыть). Это не переписанная игра, а живой деплой
проекта (`Project.embedUrl`).

Запуск приходит из двух мест и сводится app-слоем:

- кнопка **▶ Запустить** на детали проекта;
- команда консоли `run <cmd>` — по `Project.runCommand` (например `run 2048`).

`RunnerView` — **презентационный слой**: проект (заголовок + URL) и размер окна
приходят пропами. Глобальное состояние (что запущено) держит `RunnerProvider`.

---

## Безопасность встраивания

iframe изолирован через `sandbox="allow-scripts allow-same-origin"`: проекту
разрешены скрипты и его собственное хранилище (например, рекорд в localStorage),
но запрещены навигация верхнего уровня и попапы. Пока проект грузится, поверх
iframe показывается заглушка.

---

## Устойчивость к недоступному проекту

Ссылка на проект (`Project.embedUrl`) приходит с бэкенда и правится в админке —
значит, при переезде проекта сайт передеплоивать не нужно. Но старый/битый URL
не должен «вешать» окно вечным спиннером. Кросс-доменный iframe **не отдаёт**
`onError` при мёртвом хосте, поэтому провал ловим по таймауту (`loadTimeoutMs`,
по умолчанию 8 с) плюс `onError` как быстрый путь. При провале вместо спиннера
показывается **bash-подобная ошибка** в окне, а контейнер шлёт тост-уведомление
(`onError`). Окно остаётся открытым — пользователь закрывает его сам.

## Доступность

- Окно — модальный `dialog` (`aria-modal`) с названием проекта; Escape и красный
  свет закрывают его, при закрытии фокус возвращается тому, кто запустил проект.
- После загрузки фокус уходит в iframe — управление сразу попадает в проект.

## Связанные компоненты

- [`WindowChrome`](?path=/docs/shared-components-window--docs) — «светофор» окна.
- [`Tray`](?path=/docs/shared-components-tray--docs) / [`DockPill`](?path=/docs/shared-components-dockpill--docs) — свёрнутое окно.

---

# Ответственность

`RunnerView` отвечает за раскладку окна и встраивание проекта. **Не отвечает** за
то, какой проект запущен (`RunnerProvider`), и за поиск проекта по команде (app-слой).
