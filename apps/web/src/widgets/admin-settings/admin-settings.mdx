# Widgets / AdminSettings

Вкладка «Настройки приложения» личного кабинета — форма `PATCH /api/settings` по
макету: **название сайта** и **пароль раздела Interview** (текстовые поля с валидацией),
**язык** и **тема** по умолчанию ([`Segmented`](?path=/docs/shared-components-segmented--docs),
`role=radiogroup`), а также тумблеры поведения — **свечение курсора в консоли** и
**блок активности на главной** ([`Toggle`](?path=/docs/shared-primitives-toggle--docs),
`role=switch`).

Документируется **презентационный** `AdminSettingsView`; контейнер `AdminSettings`
тянет настройки и сохраняет с тостом. Настройки — синглтон, значения не локализуются.
Сохранение доступно только при изменениях (`isDirty`); пустое название / короткий
пароль блокируют отправку.

## Доступность

- Сегменты — `Segmented` (`role=radiogroup` + `role=radio`, стрелки/Home/End).
- Тумблеры — `Toggle` (`role=switch` + `aria-checked`), с текстовой подписью.
- Текстовые поля подписаны через `<label>`; ошибка валидации — `aria-describedby`.

## Ответственность

Форма настроек сайта. **Не отвечает** за загрузку/сохранение (контейнер) и
оболочку вкладок (`pages/admin`).
