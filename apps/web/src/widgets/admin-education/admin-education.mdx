# Widgets / AdminEducation

Вкладка «Образование» личного кабинета — **всегда редактируемые карточки** по двум
секциям: высшее образование (`MAIN`) и курсы/сертификаты (`ADDITIONAL`). «+ запись»/
«+ курс» добавляют карточку, корзина удаляет, а одно **«Сохранить»** отправляет все
изменения пакетом.

Локализованные поля (степень, учебное заведение) правятся в **активной локали**:
в тело уходит только текущий язык, вторую бэкенд домёрживает (`mergeText`). При
создании базовая локаль `ru` заполняется всегда — публичный экран падает на неё
фолбэком.

Документируется **презентационный** `AdminEducationView` (держит локальные строки,
по «Сохранить» отдаёт текущие строки + id удалённых). Контейнер `AdminEducation`
считает разницу и шлёт `create`/`update`/`delete` одним пакетом с тостом; мутации
инвалидируют тег `Education` — публичный экран образования тоже обновляется.

## Возможности

- Две секции по типу записи, у каждой — своя кнопка добавления.
- Карточки всегда редактируемы (степень / место / период); курсы — степень + период.
- Период — два поля-месяца (`EducationPeriod`): начало обязательно, окончание — нет
  (курс одной датой). Окончание раньше начала подсвечивается и блокирует «Сохранить».
- Порядок записей задаёт дата начала (свежее выше) — сортирует бэкенд, ручной сортировки нет.
- Пакетное «Сохранить»: контейнер по разнице строк шлёт create/update/delete.
- Правки идут в активную локаль приложения.

## Доступность

- Поля имеют `aria-label`, кнопки удаления — тоже.
- Секции размечены заголовками.

## Ответственность

Редактор списка образования. **Не отвечает** за загрузку/мутации (контейнер) и
оболочку вкладок (`pages/admin`).
