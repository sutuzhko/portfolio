# Console

Терминальная консоль-палитра (⌘K / Ctrl+K), оверлей поверх всей страницы (макет
`design/redesign` → CONSOLE). Открывается из шапки (`>_`), плашки терминала в геро
и клавиатурного ярлыка; на тач-устройствах — тапом (шорткатов нет).

Показанный здесь `ConsoleView` — **презентационный слой**: всё состояние (лента,
ввод, размер окна) приходит пропами. Оркестрацию (сессия команд, сервисы
приложения, глобальное открытие) держит контейнер `widgets/console` и
`ConsoleProvider`.

---

## Единый реестр команд

Всё поведение терминала описано в одном месте — `model/commands.ts`. Команда
получает контекст с сервисами (навигация, тема, профиль, скачивание CV, закрытие)
и колбэками вывода (`print` / `printHelp` / `clear`). Добавить команду — значит
дописать запись в реестр; справка (`help`) строится из него же, поэтому новые
команды появляются в ней автоматически.

Набор bash-подобный: навигация по «файловой системе» (`ls`, `cd`, `pwd`, `cat`),
идентификация (`whoami`, `location`, `date`, `uname`, `neofetch`), утилиты (`echo`,
`history`, `man`, `theme`, `open`, `resume`, `sudo`, `clear`, `exit`).
Каталоги (`projects/`, `experience/`, `contact/`) навигируют по разделам, файлы
(`stack.txt`, `about.md`, `skills.txt`, `contact.txt`) собираются из профиля.
Команды раннера (`run 2048`) и тостов (`notify`) подключат свои записи в тот же
реестр, когда появятся фичи.

## Доступность

- Окно — модальный `dialog` (`aria-modal`) с фокусом на скрытом поле ввода и
  ловушкой Tab, чтобы фокус не уходил на страницу под оверлеем.
- Лента — `role="log"` `aria-live="polite"`: скринридеры озвучивают новый вывод.
- Закрытие — Escape, красный свет и клик по фону; ⌘K/Ctrl+K переключают консоль.
- При закрытии фокус возвращается элементу, из которого консоль открыли.

# Ответственность

`ConsoleView` отвечает за раскладку окна и рендер ленты. **Не отвечает** за
выполнение команд (реестр `model/commands.ts`), состояние сессии
(`useConsoleSession`) и глобальное открытие (`ConsoleProvider`).
