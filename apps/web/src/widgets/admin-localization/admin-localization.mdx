# Widgets / AdminLocalization

Вкладка «Локализация» личного кабинета — сводная сверка **RU ↔ EN** по всему
редактируемому контенту. В одной таблице собраны локализуемые поля профиля, проектов,
опыта и образования; каждую ячейку можно править на месте, а весь дифф — сохранить
одной кнопкой.

Документируется презентационный **`AdminLocalizationView`**: покрытие EN и статистика,
поиск с фильтрами (Все / Проблемы / Нет EN / = RU / Изменённые), таблица по секциям с
флагами строк и плавающая панель «Сохранить N».

Строки и их адреса собирает `model/loc-sources` (реестр источников), чистую логику
диффа/статистики/фильтра — `model/loc-rows`. Контейнер `AdminLocalization` тянет
admin-данные сущностей и по «Сохранить» **раскидывает правки PATCH-ами** по их
эндпоинтам (инвалидация тегов обновляет строки серверными значениями).

**UI-строки приложения** (`translation.json`) сюда НЕ входят — они живут в репозитории,
а не в CMS. **База знаний** исключена по задумке (ведётся на одном языке).

## Возможности

- Покрытие EN в процентах + статистика: переведено / нет EN / совпадает с RU / всего.
- Поиск по ключу и тексту + фильтры, в том числе «Изменённые» (только строки диффа).
- Флаги строки: «нет EN» (жёлтый), «= RU» (перевод не сделан), «изменено» (в диффе).
- Инлайн-правка ячейки: textarea, ⌘↵ — сохранить черновик, Esc — отмена.
- Плавающая панель диффа: «Сохранить N» (фан-аут PATCH) и «Отменить» (сброс правок).

## Доступность

- Поиск и кнопки-карандаши имеют `aria-label`/`title`; фильтры — `aria-pressed`.
- Панель сохранения размечена `role="status"` — счётчик диффа объявляется ассистивно.

## Ответственность

Отображение таблицы сверки и её локального состояния (поиск, фильтр, редактируемая
ячейка — пропами). **Не отвечает** за загрузку данных, дифф и фан-аут PATCH — это
контейнер `AdminLocalization` поверх `entities/*` и `model/loc-sources`.
