# Widgets / AdminKb / ArticleViewer

Правая панель «Базы знаний» в режиме **просмотра**. Показывает выбранную статью:
чипы-теги, дату обновления, тело в Markdown (через общий `entities/kb` `KbMarkdown`
с поддержкой вики-ссылок `[[slug]]`) и блок бэклинков «↩ Ссылаются сюда». Есть кнопка
«Редактировать».

Компонент **презентационный** и покрывает три состояния одним входом: нет выбора →
приглашающее пустое состояние, загрузка → скелетон, есть статья → контент.

## Возможности

- Теги, дата обновления, тело в Markdown, бэклинки.
- Вики-ссылки `[[slug]]` и бэклинки зовут `onNavigate(slug)`.
- «Редактировать» переключает панель в режим редактора.

## Доступность

- Кнопки («Редактировать», бэклинки) операбельны с клавиатуры.
- Пустое состояние и скелетон не оставляют «пустых дыр» при загрузке.

## Ответственность

Отрисовка статьи и пустого/загрузочного состояний. **Не отвечает** за загрузку данных
и переходы (контейнер `AdminKb`).
