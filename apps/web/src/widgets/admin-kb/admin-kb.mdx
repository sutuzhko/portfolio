# Widgets / AdminKb

Вкладка «База знаний» личного кабинета — двухпанельный wiki-редактор. Документируется
левая панель **`KbLibrary`**: дерево папок и статей со счётчиками, кнопки «новая папка»/
«новая статья», инлайн-форма создания папки, инлайн-переименование и **контекст-меню**
узла (переименовать / статья сюда / подпапка / переместить в / удалить).

Панель **презентационная**: раскрытие, открытое меню и режим переименования — её
локальное UI-состояние; все доменные действия уходят колбэками наружу. Контейнер
`AdminKb` связывает их с `entities/kb` (мутации инвалидируют тег `Kb` — дерево и
открытая статья обновляются сами).

Правки идут в **активную локаль** приложения (вторую домёрживает бэкенд).

## Возможности

- Дерево папок/статей с раскрытием, счётчиками и подсветкой выбранной статьи.
- Создание папки (инлайн-форма с выбором родителя) и статьи (в корне или в папке).
- Инлайн-переименование; мутация уходит **только при реальном изменении** имени.
- Контекст-меню: переименовать / статья сюда / подпапка / переместить в / удалить.
- «Переместить в» исключает текущее расположение узла (нет перемещения «на месте»).

## Доступность

- Кнопки узлов и действий имеют текст или `aria-label` («Действия», «Новая папка»).
- Меню размечено ролями `menu`/`menuitem`; клик по фону закрывает его.
- Переименование фокусирует поле; Enter — сохранить, Esc — отменить.

## Ответственность

Дерево библиотеки и его UI-состояние. **Не отвечает** за загрузку/мутации (контейнер
`AdminKb`), просмотр/редактор статьи (`KbArticleViewer` / `KbArticleEditor`) и оболочку
вкладок (`pages/admin`).
