# Widgets / KbTree

Боковое дерево базы знаний: папки и статьи. Строится из `DatabaseTreeDto` поверх
UI-kit [`Tree`](?path=/docs/shared-components-tree--docs) — клик по статье выбирает
её, папки раскрываются сами, работает клавиатурная навигация.

**Презентационный**: данные и выбор приходят пропами. Пока дерево грузится
(`tree === undefined`) — скелетон.

## Доступность

- Контейнер — `<nav>` с `aria-busy` во время загрузки.
- Клавиатура и роли (`tree`/`treeitem`/`group`) — от UI-kit `Tree`.

## Ответственность

Отвечает за разворачивание дерева БЗ в узлы `Tree` (папки → статьи по slug) и
скелетон загрузки. **Не отвечает** за загрузку данных и чтение статьи (это страница
и `KbArticle`).
