# Widgets / AdminStack

Вкладка **«Стек и языки»** личного кабинета — одна карточка с общим «Сохранить»
(пакетное сохранение). Технологии и навыки правятся **прямым манипулированием** —
без отдельных полей ввода:

- **Технологии** — чипы, разложенные по блокам-категориям в сетке-грид (**максимум 3
  колонки**, лишние блоки переносятся на след. ряд; адаптивно 2/1). Каждый чип
  **перетаскивается за грип-ручку** (dnd-kit, мышь + клавиатура) — правит **очерёдность
  отображения** внутри блока; порядок сохраняется в `Technology.order`, поэтому главная
  показывает стек в той же последовательности (бэкенд сортирует по `order`). При
  наведении на заголовке категории — **карандаш** (инлайн-переименование блока) и
  **корзина** (удаление блока целиком: его технологии уходят на удаление, обратимо до
  «Сохранить»); в блоке — **чип-кнопка «+»** (раскрывает пустой инлайн-чип для ввода
  технологии); у заголовка «Технологии» — **«+ блок»** (новая категория с инлайн-именем).
  Чип удаляется крестиком.
- **Языки** — редактируемые строки (название в активной локали · уровень · % владения),
  «+ язык» / корзина.
- **Навыки** — тот же паттерн, что технологии, но без категорий: плоский блок, «+» в нём
  раскрывает инлайн-чип. Показываются на экране «Опыт».

**Категория — это поле `category` на технологии** (отдельной сущности нет), поэтому у
неё локальный ключ (переименование не рвёт связь чипов), а переименование блока на
сохранении = смена `category` у всех его технологий (`PATCH`). Пустой безымянный блок
на сохранении отбрасывается.

Правки копятся **локально**; по «Сохранить» контейнер `AdminStack` считает разницу и
шлёт мутации пакетом: технологии — create новых / update переименованных категорий /
delete убранных; языки — create / update / delete строк; навыки — create / delete.
Инвалидация тегов `Technology`/`Language`/`Skill` обновляет главную и экран «Опыт».
`key` контейнера пересобирает форму после сейва (у новых записей — реальные id).

## Возможности

- Прямое редактирование: карандаш/корзина блока, «+»-чип для добавления, «+ блок».
- **Drag&drop порядка чипов** (`SortableChip` на dnd-kit): грип-ручка, мышь + клавиатура; порядок → `Technology.order`, отражается на главной.
- Инлайн-ввод (`InlineEdit`): авто-фокус, Enter/blur — коммит, Escape — отмена, пустое — отбрасывается.
- Строки языков: название (активная локаль) / уровень CEFR / % (нормализуется 0…100).
- **«Сохранить» активна только при изменениях** (слепок текущего состояния vs начального).
- Одно «Сохранить» — пакетный дифф create/update/delete по трём сущностям.

## Доступность

- Крестик чипа, карандаш категории, «+»-кнопки и корзина строки имеют `aria-label`.
- Инлайн-поля подписаны (`aria-label`); ховер-контролы остаются в фокусируемом дереве
  (раскрываются и по `:focus-within`, не только по `:hover`).

## Ответственность

Отрисовка формы и сбор локального диффа. **Не отвечает** за загрузку/мутации —
это контейнер `AdminStack` поверх `entities/technology`/`language`/`skill`.
