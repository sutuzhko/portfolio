# About

Секция «Обо мне» главной (макет `design/redesign` → ABOUT) — заголовок `// обо мне`
и текст-био в несколько абзацев со ссылками.

---

## Анатомия

- `SectionLabel` (`// обо мне`) + `.prose` с Markdown через `react-markdown`.
- Ссылки открываются в новой вкладке (`target="_blank" rel="noopener noreferrer"`);
  сырой HTML не рендерится (безопасно по умолчанию).
- Био — `profile.bioMarkdown` (локализовано); пока грузится — скелетон-абзацы.

## Доступность

- Заголовок секции — `<h2>` (`SectionLabel`).
- Внешние ссылки безопасны: `rel="noopener noreferrer"`; на время загрузки контейнер —
  `aria-busy`/`aria-live`.

## Связанные компоненты

- [`SectionLabel`](?path=/docs/shared-primitives-sectionlabel--docs) / [`Skeleton`](?path=/docs/shared-primitives-skeleton--docs) — из чего собрана.
- `Widgets/PageIntro` — короткое интро на других экранах (тоже серверный текст).

---

# Ответственность

About отвечает за отображение и типографику био. **Не отвечает** за загрузку профиля
(получает `bioMarkdown`/`isLoading` пропсами) и за разметку контента — её задаёт автор
в CMS через Markdown.
