# Featured

Секция избранных проектов главной (макет `design/redesign` → FEATURED PROJECTS) —
плитки-градиенты с категорией, названием, описанием, аватарами контрибьюторов и
тегами технологий, плюс ссылка «Все проекты».

---

## Анатомия

- Заголовок `// избранные проекты` + ссылка «Все проекты» (`onViewAll`).
- Плитка — семантическая `<button>` (открытие детали, `onSelect(slug)`); заливка из
  `tileColor` со штриховкой и затемнением, чтобы текст читался на любом цвете.
- Аватары и теги ограничены по числу/ширине, остаток сворачивается в `+N`.
- Пока данных нет — скелетоны.

## Доступность

- Плитка — настоящая `<button>` (фокус, клавиатура), а не `div` с `onClick`.
- Фон декоративен; заголовок/описание несут смысл. Затемнение обеспечивает контраст текста.

## Связанные компоненты

- `entities/project` → `ProjectBackground` — заливка плитки.
- [`Avatar`](?path=/docs/shared-primitives-avatar--docs) — контрибьюторы; [`SectionLabel`](?path=/docs/shared-primitives-sectionlabel--docs) — заголовок.

---

# Ответственность

Featured отвечает за раскладку и отображение плиток. **Не отвечает** за запрос списка
проектов и за выбор «избранных» (это делает страница по флагу `pinned`).
