# Stack

Секция технологического стека главной (макет `design/redesign` → STACK) — заголовок
`// стек` и карточки-слои (Frontend / Backend / Tooling), каждая со списком меток
технологий.

---

## Анатомия

- `SectionLabel` (`// стек`, локализуется) + грид карточек-слоёв.
- Технологии приходят с бэкенда (`entities/technology`, поле `category`) и группируются
  по слою хелпером `groupTechnologies`; метки — `Tag`.
- Пока грузятся — `Skeleton` карточек.

## Доступность

- Заголовок секции — `<h2>` (`SectionLabel`), встроен в порядок заголовков страницы.
- На время загрузки грид помечен `aria-busy`/`aria-live`.

## Связанные компоненты

- [`SectionLabel`](?path=/docs/shared-primitives-sectionlabel--docs) / [`Card`](?path=/docs/shared-primitives-card--docs) / [`Tag`](?path=/docs/shared-primitives-tag--docs) — из чего собрана.

---

# Ответственность

Stack отвечает за раскладку заголовка и карточек-слоёв и скелетон загрузки. **Не
отвечает** за источник данных стека (`entities/technology`, запрос делает контейнер
страницы) и за группировку (хелпер `groupTechnologies`).
