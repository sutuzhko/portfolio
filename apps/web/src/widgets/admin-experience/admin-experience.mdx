# Widgets / AdminExperience

Вкладка «Опыт работы» — **список** мест работы. Добавление и правка ведут на
отдельные детальные маршруты (`/admin/experience/:locale/new` и `/:id`), поэтому
форма живёт на своём URL, а смена локали пересобирает её на данных нужного языка.
Форма документируется отдельно — `Widgets/AdminExperience/Form`.

`AdminExperienceView` презентационный: список, значок «сейчас», удаление с
подтверждением. Контейнер `AdminExperience` по детальному сегменту маршрута
показывает список или форму и дергает мутации (тег `Experience` → публичный экран
опыта обновляется).

## Ответственность

Список и удаление. **Не отвечает** за форму (отдельный маршрут/компонент),
загрузку/мутации (контейнер) и оболочку вкладок (`pages/admin`).
