# Widgets / AdminExperience / Form

Форма места работы (создание/правка) — на отдельном детальном маршруте
(`/admin/experience/:locale/new` или `/:id`). Локализованные поля (роль, локация,
достижения) правятся в **активной локали** маршрута; вторую бэкенд домёрживает.

- Период — месяцами (`type="month"`, `YYYY-MM ↔ ISO`); «текущее место» — тумблер
  (при нём окончание не задаётся).
- Достижения — textarea, по строке на пункт.
- Технологии — мультиселект чипами по существующему стеку (хранятся id).
- База `ru` при создании заполняется всегда (публичный фолбэк).
