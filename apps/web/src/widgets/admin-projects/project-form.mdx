# Widgets / AdminProjects / Form

Форма проекта (создание/правка) на отдельном детальном маршруте. Локализованные
поля (название, краткое/полное описание, роль, ключевые пункты, ссылки) правятся в
**активной локали** маршрута; вторую бэкенд домёрживает.

- Технологии\* — мультиселект чипами по существующим записям (id).
- Коллабораторы — `ContributorManager`: выбор чипами + инлайн-CRUD каталога
  (создание/правка/удаление участников).
- Цвет плитки — палитра с превью-градиентом.
- Ссылки — textarea «Название | https://…» построчно.
- Статус (черновик/опубликован), «скрыт», «в избранном», «запускается в браузере»
  (при нём появляются поля iframe-URL и команды запуска).
- База `ru` при создании заполняется всегда (публичный фолбэк).
