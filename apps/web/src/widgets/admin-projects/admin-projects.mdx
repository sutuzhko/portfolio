# Widgets / AdminProjects

Вкладка «Проекты» — **список** проектов (плитка-градиент, значок «избранное»,
бейдж «скрыт», теги, статус). Добавление и правка ведут на отдельные детальные
маршруты (`/admin/projects/:locale/new` и `/:id`), поэтому форма живёт на своём
URL, а смена локали пересобирает её на данных нужного языка. Форма документируется
отдельно — `Widgets/AdminProjects/Form`.

`AdminProjectsView` презентационный; контейнер `AdminProjects` по детальному
сегменту маршрута показывает список или форму, тянет проекты + технологии +
контрибьюторов и дергает мутации (тег `Project` → публичные экраны обновляются).

## Ответственность

Список и удаление. **Не отвечает** за форму (отдельный маршрут/компонент),
загрузку/мутации (контейнер) и оболочку вкладок (`pages/admin`).
