# Widgets / AdminProjects / ContributorManager

Управление участниками (коллабораторами) прямо в форме проекта. Co-located здесь вся
работа с общим каталогом контрибьюторов: **выбор** участников в проект (чипы-тогглы),
**создание**, **правка** и **удаление** каталожных записей. Форма проекта лишь
прокидывает выбранные id и CRUD-колбэки — вёрстка и состояние редактора живут тут.

## Состояния

### Создание

Кнопка «+ создать участника» разворачивает инлайн-форму (имя в активной локали, цвет
аватара, опциональная ссылка). После успеха новый участник сразу выбирается в проекте.

<Canvas of={Stories.Creating} />

### Правка

У каждого чипа — карандаш: открывает ту же форму, предзаполненную значениями записи, с
кнопкой «Удалить» (через `ConfirmDialog`).

<Canvas of={Stories.Editing} />

## Локализация имени

Имя правится в **активной локали**, но бэкенд **перезаписывает** его целиком
(`writeText`), поэтому в тело запроса уходят **обе локали**: активную берём из формы,
вторую несём из текущей записи — перевод не теряется. Для нового участника, введённого
в EN, дублируем значение в обязательный `ru`.

## Ответственность

Чипы-выбор + инлайн-CRUD каталога + подтверждение удаления. **Не отвечает** за сетевые
запросы (контейнер `AdminProjects`) и за остальную форму проекта (`ProjectForm`).
