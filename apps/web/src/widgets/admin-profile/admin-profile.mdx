# Widgets / AdminProfile

Вкладка «Профиль» личного кабинета — форма `PATCH /api/profile` на **React Hook Form
+ Zod**. Локализованные поля правятся в **активной локали** (язык приложения) — бейдж
RU/EN в шапке показывает, что редактируется; на сохранении уходит только эта локаль,
вторую бэкенд мёржит (не затирает).

Документируется **презентационный** `AdminProfileView`; контейнер `AdminProfile`
тянет админ-профиль (`getProfileAdmin`), сохраняет и показывает тост.

## Возможности

- Скалярные поля: имя, email, цвет аватара, ссылка на резюме.
- Двуязычные (`{ ru, en }`): роль, локация, питч, «о себе», интро экранов Проекты/Опыт/Контакты.
- Показатели (`highlights`) — редактируемый список «значение + подпись».
- `heroStack` — строка через запятую (разбивается при сохранении).
- Доступность (`Segmented`) и скрытие блока «Обо мне» (`Toggle`).

## Доступность

- Локализованное поле — одиночный Input/Textarea в активной локали; язык приложения
  задаёт, что редактируется (бейдж RU/EN в шапке).
- Валидация Zod: обязательность локализованного поля — только для базовой локали `ru`
  (при правке `en` пустое значение допустимо, перевод может отсутствовать).

## Ответственность

Форма профиля и маппинг формы ↔ DTO (`profileToForm`/`formToUpdate`). **Не отвечает**
за загрузку/сохранение (это контейнер) и за оболочку вкладок (`pages/admin`).

Не покрыто этой вкладкой (отдельные эндпоинты/фичи): контакты (`/profile/contacts`),
загрузка фото аватара (media).
