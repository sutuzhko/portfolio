# Highlights

Секция ключевых показателей главной (макет `design/redesign` → HIGHLIGHTS) — ряд
карточек «крупное значение + подпись»: стаж, число построенных UI-kit'ов, уровень
языка, ранг Codewars. Идёт сразу под геро-полосой, поэтому **без заголовка секции**
(в отличие от `Stack`).

---

## Анатомия

- Семантический список `<ul>/<li>` — перечисление однотипных фактов («список из 4»).
- Каждый элемент — `Card` с крупным значением и подписью (`Text`).
- Данные — `profile.highlights` (`[{ value, label }]`, подпись уже локализована);
  пока грузятся — `Skeleton` той же раскладки.

## Доступность

- `<ul>/<li>` озвучивается как список с числом элементов.
- На время загрузки список помечен `aria-busy`/`aria-live` (объявит появление данных).

# Ответственность

Highlights отвечает за раскладку, вывод показателей и скелетон загрузки. **Не
отвечает** за источник данных — значения и подписи приходят пропсом `items` из
`profile.highlights` (запрос делает контейнер страницы).
