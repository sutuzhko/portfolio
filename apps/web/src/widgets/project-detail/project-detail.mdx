# ProjectDetail

Деталь проекта (макет `design/redesign` → PROJECT DETAIL): шапка-баннер с градиентным
фоном (переиспользует `entities/project` → [`ProjectBackground`](?path=/docs/entities-project-background--docs)),
основная колонка (описание в Markdown, список «что внутри», галерея) и боковая
карточка (роль, период, стек, ссылки).

---

## Анатомия

- **Баннер** — `ProjectBackground` + заголовок/категория.
- **Кнопка «▶ Запустить»** — у запускаемого проекта (`runnable` + `embedUrl`):
  открывает [`Runner`](?path=/docs/widgets-runner--docs), который встраивает проект
  через iframe. Рядом — подсказка управления (`runHint`).
- **Тело** — `bodyMarkdown` (react-markdown) + буллеты «что внутри» + галерея;
  галерея и «что внутри» рендерятся **только при наличии данных**.
- **Сайдбар** — роль, период, стек, внешние ссылки.
- Пока данных нет — скелетон той же раскладки.

## Доступность

- Заголовок проекта — `h1`; секции тела — семантические заголовки.
- Внешние ссылки открываются безопасно (`rel="noopener"`); баннер декоративен.

## Связанные компоненты

- [`ProjectBackground`](?path=/docs/entities-project-background--docs) — фон баннера.
- `Pages/Project` — контейнер, который запрашивает деталь по slug.

---

# Ответственность

ProjectDetail отвечает за раскладку и отображение детали. **Не отвечает** за запрос
проекта и навигацию — это страница `ProjectPage`.
