# RootLayout

Корневая оболочка приложения (слой `app`): липкий `Navbar` сверху, контент маршрута
(`<Outlet/>`) по центру, `Footer` снизу. Все публичные маршруты обёрнуты в неё в
`app/router`.

---

## Анатомия

- `flex-column` + `min-height: 100vh` — подвал прижат к низу даже на коротком контенте.
- **Каждая страница рендерит свой `<main>`** — лейаут его не навязывает.
- `Navbar` берёт имя владельца из профиля (`useProfile`) для копирайта подвала.

## Доступность

- Три landmark-региона: `banner` (навбар), `main` (контент страницы), `contentinfo`
  (подвал) — навигация по регионам для скринридеров.
- Skip-link «к содержимому» появится здесь после согласования `position: absolute`
  (стандартный off-canvas a11y-паттерн).

## Связанные компоненты

- `Widgets/Navbar` / `Widgets/Footer` — глобальная обвязка.

---

# Ответственность

RootLayout собирает глобальную обвязку вокруг маршрута. **Не отвечает** за содержимое
страниц и за консоль (её триггер в навбаре пока заглушён — придёт отдельным срезом FE-2).
