# LangSwitch

Фича переключения языка (ru ↔ en). Собрана **из UI Kit** — `Button variant="icon"`
с моноширинной подписью кода локали, а не собственный `<button>`. Показывает текущий
код (`RU`/`EN`) и циклит локали через `useLanguage` (i18next).

---

## Анатомия

- `Button variant="icon"` с текстом-кодом (`RU`/`EN`) вместо иконки.
- Состояние — из `useLanguage()`; клик вызывает `toggleNext`.

# Когда использовать

- в правом блоке навбара как переключатель языка всего приложения.

# Когда **не** использовать

- при трёх и более языках — переключатель кодом становится неочевиден, нужен список/меню.

---

## Доступность

- Кнопка несёт `aria-label`/`title` «Переключить язык»; видимый код (`RU`/`EN`) —
  дополнительная визуальная подсказка.
- Смена локали перезапрашивает серверный контент (кэш RTK Query сегментирован по языку) —
  это делает слой данных, не фича.

## Связанные компоненты

- [`Button`](?path=/docs/shared-primitives-button--docs) — из чего собрана.
- [`ThemeSwitch`](?path=/docs/features-themeswitch--docs) — сосед в навбаре.

---

# Ответственность

Переключить локаль по клику и показать текущий код. **Не отвечает** за перевод контента
(это i18n-ресурсы) и за раскладку навбара.
