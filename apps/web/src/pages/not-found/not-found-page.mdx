# Not Found

Страница 404 — показывается для несуществующих маршрутов (в роутере путь `*`).
Статичная: крупный код `404`, заголовок, пояснение и ссылка на главную. Данных с
сервера нет, поэтому и состояния загрузки нет.

---

## Анатомия

- Крупный декоративный код `404`, заголовок (`h1`), пояснение и ссылка на главную (`<Link>`).
- Тексты — из i18n (`notFound.*`); навигация — через роутер.

---

## Состояния

Единственное — статичный экран (плюс адаптив). Загрузки/ошибки/пусто здесь нет.

## Доступность

- Заголовок — `h1`; ссылка «На главную» имеет доступное имя и работает с клавиатуры.
- Крупный код `404` — декоративный акцент, смысл несут заголовок и текст.

## Связанные компоненты

- `Pages/Forbidden` (403) и `Pages/ServerError` (500) — родственные экраны статусов.

---

# Ответственность

Сообщает пользователю о неверном маршруте и возвращает на главную. **Не отвечает** за
данные (их тут нет) — только текст (i18n) и ссылку (роутер).
