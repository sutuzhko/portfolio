# Forbidden

Страница 403 — нет прав доступа. Показывается гардами приватной зоны (кабинет, база
знаний) при попытке открыть защищённый маршрут без авторизации (подключение — в FE-3).
Статичная: крупный код `403`, заголовок, пояснение и ссылка на главную.

---

## Анатомия

- Крупный декоративный код `403`, заголовок (`h1`), пояснение и ссылка на главную.
- Тексты — из i18n (`forbidden.*`); навигация — через роутер.

## Доступность

- Заголовок — `h1`; ссылка «На главную» доступна с клавиатуры.
- Код `403` декоративен; смысл несёт текст.

## Связанные компоненты

- `Pages/NotFound` (404) и `Pages/ServerError` (500) — родственные экраны статусов.

---

# Ответственность

Сообщает об отсутствии прав и возвращает на главную. **Не отвечает** за сам гард
доступа (гарды приватной зоны, FE-3) — только за отображение статуса.
