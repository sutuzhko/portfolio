# Server Error

Страница 500 — общий фолбэк при ошибке рендера или загрузки маршрута. Подключена как
`errorElement` корневого маршрута роутера, поэтому ловит исключения любой страницы.
Ссылка «на главную» делает **полную перезагрузку** — это сбрасывает ошибочное
состояние роутера.

---

## Анатомия

- Крупный декоративный код `500`, заголовок (`h1`), пояснение и ссылка на главную (`<a>`,
  не `<Link>` — нужна полная перезагрузка).
- Тексты — из i18n (`serverError.*`).

## Доступность

- Заголовок — `h1`; ссылка «На главную» доступна с клавиатуры.
- Код `500` декоративен; смысл несёт текст.

## Связанные компоненты

- `Pages/NotFound` (404) и `Pages/Forbidden` (403) — родственные экраны статусов.

---

# Ответственность

Ловит непойманные ошибки маршрута и даёт выход на главную (с полной перезагрузкой).
**Не отвечает** за конкретную причину ошибки — это общий фолбэк.
