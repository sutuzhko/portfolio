# Home

Главная страница (макет `design/redesign` → HOME) — витрина: геро, показатели,
«обо мне», стек, активность, баннер доступности и избранные проекты.

---

## Анатомия

- **Контейнер** `HomePage` — оркеструет запросы (профиль, статистика GitHub/Codewars,
  проекты), скролл-шпион и навигацию; **вид** `HomePageView` — собирает секции из
  виджетов (данные + `isLoading` пропсами).
- Почти всё — с бэкенда: профиль (идентичность/питч/«обо мне»/показатели/доступность),
  стек (`entities/technology`), статистика, избранное. Каждая секция скелетонит свою раскладку.

## Доступность

- Порядок заголовков секций держится через `Heading`/`SectionLabel`; ошибка — `role="alert"`.
- Секции при загрузке — `aria-busy`/`aria-live`; анимации уважают `prefers-reduced-motion`.

## Связанные компоненты

- Виджеты: `Hero`, `Highlights`, `About`, `Stack`, `Activity`, `OpenToWork`, `Featured`.

---

# Ответственность

`HomePageView` отвечает за раскладку секций и распределение состояний загрузки. **Не
отвечает** за запросы к API, скролл-шпион и навигацию — это контейнер `HomePage`.
