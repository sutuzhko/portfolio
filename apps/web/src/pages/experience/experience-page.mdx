# Experience

Экран опыта работы (маршрут `/experience`, макет → EXPERIENCE): шапка-«крошка»,
серверное интро (`shared/ui/PageIntro`), **таймлайн** мест работы
(`widgets/experience-timeline`) и блок образование/языки/навыки
(`widgets/resume-details`).

---

## Анатомия

- **Контейнер** `ExperiencePage` — оркеструет запросы (опыт, образование, языки, навыки,
  профиль для интро) + навигация; **вид** `ExperiencePageView` — раскладка (данные пропсами).
- Ведущее состояние (loading/error) — по опыту как основному блоку; остальные блоки
  скелетонят независимо.

## Доступность

- Заголовок — `h1`; ошибка — `role="alert"`; блоки при загрузке — `aria-busy`/`aria-live`.

## Связанные компоненты

- `Widgets/ExperienceTimeline` / `Widgets/ResumeDetails` — из чего собран.
- [`PageIntro`](?path=/docs/shared-components-pageintro--docs) — серверное интро.

---

# Ответственность

`ExperiencePageView` отвечает за раскладку экрана и переход назад. **Не отвечает** за
запросы — это контейнер `ExperiencePage`.
