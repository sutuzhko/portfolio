# Projects

Экран списка проектов (макет `design/redesign` → PROJECTS) — шапка-«крошка»,
серверное интро (`shared/ui/PageIntro`), панель поиска и фильтров, сетка карточек.

---

## Анатомия

- **Контейнер** `ProjectsPage` — запрашивает проекты и профиль для интро, навигация;
  **вид** `ProjectsPageView` — раскладка и состояния (данные + `isLoading` пропсами).
- Фильтрация (поиск + фасеты) — на клиенте (`useProjectFilter`): набор мал, отклик мгновенный.
- Клик по карточке → страница проекта (`onOpenProject`).

## Доступность

- Заголовок — `h1`; карточки — кнопки; ошибка — `role="alert"`; пусто — понятный текст + действие.
- На время загрузки сетка — `aria-busy`/`aria-live`.

## Связанные компоненты

- `Widgets/ProjectList` / `Features/ProjectFilter` — сетка и фильтры.
- [`PageIntro`](?path=/docs/shared-components-pageintro--docs) — серверное интро.

---

# Ответственность

`ProjectsPageView` отвечает за раскладку экрана, фильтрацию и состояния списка. **Не
отвечает** за запрос проектов и навигацию — это контейнер `ProjectsPage`.
