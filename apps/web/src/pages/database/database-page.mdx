# Pages / Database

Приватная база знаний (`/database`, макет `~/database`): дерево слева, читатель
статьи справа. Маршрут за гардом `RequireAuth` — гостя уводит на `/login`.

Документируется **презентационный** `DatabasePageView`; контейнер `DatabasePage`
тянет дерево и статью (`entities/kb`), держит выбранный slug и при загрузке дерева
автоматически открывает первую статью.

---

## Архитектура

- **`DatabasePage`** (контейнер) — `useDatabaseTree` + `useArticle(slug)`, автовыбор
  первой статьи, переходы (дерево, вики-ссылки, бэклинки).
- **`DatabasePageView`** — раскладка: [`KbTree`](?path=/docs/widgets-kbtree--docs) +
  [`KbArticle`](?path=/docs/widgets-kbarticle--docs). Ошибку дерева показывает на
  уровне страницы, ошибку статьи — внутри читателя.

## Доступность

- Дерево — `<nav>` с ролями `tree`/`treeitem`; читатель — `<article>`.
- Скелетоны объявляют загрузку; ошибки — через `ErrorState`.

## Связанные

- `entities/kb` — `useDatabaseTree`, `useArticle`.
- `app/router/RequireAuth` — гард приватного маршрута.
