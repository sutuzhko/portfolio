# ProjectTile

Плитка проекта (макет: PROJECTS grid) — фон-градиент, поверх которого категория,
период, название, краткое описание, аватары контрибьюторов и теги технологий.

Живёт в слое `entities/project`, потому что доменно-презентационна: знает форму
проекта, но не знает ни про навигацию, ни про фильтры. Один и тот же визуал
переиспользуют публичный список (`ProjectList`) и живой предпросмотр в кабинете —
вёрстка плитки существует ровно в одном месте.

---

## Кликабельность

- **С `onOpen`** — плитка рендерится как семантическая `<button>` (список проектов,
  клик открывает деталь).
- **Без `onOpen`** — как `<div>` (предпросмотр черновика в CRM: смотреть, но не кликать).

---

## Анатомия

- Собрана из переиспользуемых частей: [`ProjectBackground`](?path=/docs/entities-project-background--docs)
  (декоративный фон-заливка `tileColor`), `ProjectCategory`, `ProjectAvatars`, `ProjectTags`.
- Описание усечено по первому предложению + жёсткий `line-clamp:2`.
- Теги считаются по ширине (лишние → «+N»), аватары ограничены (+N).

## Доступность

- С `onOpen` — настоящая `<button>` (фокус, клавиатура); фон декоративен (`aria-hidden`).
- Доступное имя кнопки собирается из заголовка и текста плитки.

## Связанные компоненты

- [`ProjectBackground`](?path=/docs/entities-project-background--docs) — заливка плитки.
- `Widgets/ProjectList` — сетка таких плиток.

---

# Ответственность

ProjectTile отвечает за раскладку одной плитки и (опционально) переход по клику.
**Не отвечает** за фильтрацию/сортировку (это `ProjectList` и `useProjectFilter`),
загрузку данных и сам запуск проекта. Данные приходят пропсом `project`.
