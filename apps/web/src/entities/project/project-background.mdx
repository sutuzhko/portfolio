# ProjectBackground

Декоративный фон плитки проекта: заливка (`tileColor` из проекта) плюс фирменная
текстура — диагональная штриховка, «орб» в углу и затемняющий градиент снизу (чтобы
белый текст поверх читался). Вынесен отдельным компонентом-сущностью, чтобы
переиспользоваться в карточке списка, шапке детали проекта и превью выбора фона в
CMS — и покрываться историями независимо.

---

## Анатомия

- Корень — абсолютный `<span aria-hidden>` внутри relative-родителя.
- Три слоя текстуры: `stripes` (штриховка), `orb` (свечение в углу), `shade`
  (затемнение снизу под текст).

## Доступность

- Полностью декоративен (`aria-hidden`) — не участвует в озвучке. Читаемость текста
  поверх обеспечивает слой `shade`, а не цвет как таковой.

## Токены

Фолбэк — `--color-raised`; скругление задаёт родитель. Сам цвет приходит из данных
проекта (`tileColor`), а не из токенов.

## Связанные компоненты

- `Entities/Project/Tile` / `Widgets/ProjectDetail` — накладывают контент поверх фона.

---

# Ответственность

ProjectBackground отвечает только за декоративную заливку и текстуру плитки.
**Не отвечает** за контент поверх (аватары, теги, заголовок) — его накладывает
карточка-родитель — и за источник цвета (его даёт проект через `tileColor`).
