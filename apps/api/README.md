# API

Бэкенд портфолио на NestJS. Обслуживает и публичный сайт, и приватную CRM: отдаёт локализованный контент, хранит его в PostgreSQL через Prisma и закрывает админскую зону аутентификацией на JWT с ротацией refresh-токенов.

Это часть монорепо - общие с фронтендом типы генерируются отсюда (см. [контракт](../../packages/contract) и корневой [README](../../README.md)).

## Устройство

Все маршруты живут под префиксом `/api`. Публичные `GET`-эндпоинты отдают контент, приватные (CRM) требуют валидной сессии.

| Область                             | Что делает                                                                                 |
| ----------------------------------- | ------------------------------------------------------------------------------------------ |
| `auth`                              | Вход, выход, ротация refresh-токенов: HttpOnly-cookie, уникальный `jti`, отзыв при повторе |
| `profile`                           | Профиль, контакты, показатели (highlights), доступность                                    |
| `projects`                          | Проекты, контрибьюторы, галерея, ссылка на сборку для раннера                              |
| `experience` / `education`          | Опыт работы и образование                                                                  |
| `technology` / `skill` / `language` | Стек, навыки и языки                                                                       |
| `database`                          | База знаний: папки, статьи, wiki-ссылки и обратные ссылки                                  |
| `media`                             | Загрузка и обработка изображений (sharp)                                                   |
| `settings`                          | Настройки сайта: видимость секций и страниц, темы, языки, акцентный цвет                   |
| `stats`                             | Прокси к GitHub и Codewars с TTL-кэшем в памяти                                            |

Локализация хранится прямо в базе: текстовые поля - это `Json` вида `{ ru, en }`. Нужный язык выбирается на входе по query-параметру `?locale=` или заголовку `Accept-Language`, и наружу отдаётся уже одна строка.

Контракт для фронтенда - источник истины: Swagger описывает схему, из неё генерируются TypeScript-типы, а CI следит, чтобы они не разошлись с реальностью.

## Запуск

Проще всего - из корня монорепо одной командой. Она поднимает Postgres в Docker, применяет миграции и запускает API в watch-режиме:

```bash
pnpm backend
```

Отдельно, если база уже поднята:

```bash
pnpm --filter @portfolio/api dev          # watch-режим
pnpm --filter @portfolio/api start:prod   # прод-сборка
```

- Health-check: <http://localhost:3000/api/health>
- Swagger UI: <http://localhost:3000/api/docs>

Переменные окружения - в `apps/api/.env` (пример рядом, `.env.example`). Ключевые: `DATABASE_URL`, `JWT_ACCESS_SECRET` и `JWT_REFRESH_SECRET`, `ADMIN_USERNAME` и `ADMIN_PASSWORD`.

## База данных

Схема и миграции - на Prisma.

```bash
pnpm --filter @portfolio/api prisma:generate   # сгенерировать клиент
pnpm --filter @portfolio/api prisma:migrate    # создать/применить миграцию (dev)
pnpm --filter @portfolio/api prisma:seed       # засеять эталонный контент (перезаписывает!)
```

Seed не только наполняет базу, но и генерирует брендированные заглушки для галереи проектов (через sharp), чтобы на свежей базе не было битых картинок.

## Тесты

```bash
pnpm --filter @portfolio/api test        # unit (jest)
pnpm --filter @portfolio/api test:e2e    # e2e против настоящего Postgres
pnpm --filter @portfolio/api lint        # eslint --fix
```

e2e гоняются не против моков, а против реальной базы - проверяются и SQL-слой, и локализация, и приватность эндпоинтов.

## Контракт

После правки эндпоинтов - пересобрать общие типы:

```bash
pnpm contract:generate
```

Команда поднимает приложение без базы, снимает с него OpenAPI-схему и генерирует типы в `packages/contract`.
